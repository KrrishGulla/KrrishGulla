# Krrish Gulla

**Mechatronics Engineering · Manipal Institute of Technology · Class of 2027**

I work close to the hardware: firmware drivers, embedded telemetry, and navigation and control software for robots. I'm interested in how machine-learning models get optimized and compiled to run efficiently on edge hardware.

### Featured projects

| Project | What it is |
|---|---|
| [**amt-construction-navigation**](https://github.com/KrrishGulla/amt-construction-navigation) | ROS 2 and Gazebo Harmonic navigation stack for a material-carrying robot on a construction site: Hybrid A* planner, CasADi NMPC controller, and an EKF that estimates payload mass and centre of gravity online. |
| [**path-planning-benchmark**](https://github.com/KrrishGulla/path-planning-benchmark) | Toolbox-free MATLAB benchmark of 8 global planners (A*, Theta*, PRM, RRT*, APF and more) across 5 environment classes, with Monte Carlo trials, 6 metrics and TOPSIS ranking. |
| [**stm32pi**](https://github.com/KrrishGulla/stm32pi) | IoT ambulance telemetry: STM32 and a cellular modem publishing to AWS IoT Core over MQTT with TLS, plus a live dashboard. Conference paper presented at SCPGCON; patent filing in progress. |
| [**ardupilot**](https://github.com/KrrishGulla/ardupilot) (fork) | C++ CAN drivers for JIYI radar sensors (obstacle avoidance and terrain altitude), written during my internship at Marut Dronetech. |
| [**RAG_Assistant**](https://github.com/KrrishGulla/RAG_Assistant) | Document-grounded RAG assistant (Azure OpenAI, LangChain, ChromaDB) with a talking avatar, built during an internship at iSpace. |
| [**soft-actuator-fea**](https://github.com/KrrishGulla/soft-actuator-fea) | MATLAB finite-element comparison of four pneumatic soft-actuator geometries. |
